# v0.5.7 — 页面美术优化 + 版本列表计数修复

本版把 p216 的三处页面美术优化收进便携包，并修掉验收发现的一个真实 UI 问题。

## 包含

- **启动器主页**（深色双栏）：版本库 + 安装/启动主操作区，补齐此前加载即报错的
  `loadLoaderVersions` 等函数，高级设置（JVM / 模组 / 整合包）从不可用变为可用；
- **版本列表计数修复**：列表不再硬截断 400 行；`MAX_RENDERED` 上限 2000，
  计数文案与实际渲染行数一致（实测 921 行 / 921 个），超出时提示用搜索或下拉定位；
- **PCL 一键安装面板**（源码）：clam 深色主题、三步卡片、状态色、等宽日志
  （面板不在便携包内，随面板资产单独交付）；
- **下载源说明页**：吸顶导航、卡片表格、深色终端风代码块、深色模式、窄屏保护，
  外部链接 0 丢失。
