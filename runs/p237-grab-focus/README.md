# p237 — 强抢焦点后仍抓不住光标：背包键保持“未验证”

日期：2026-11-03。p235 发现合成点击抓不住光标后，本回合试 p213 用过的
`AttachThreadInput` 把焦点强行钉到游戏窗口，再点击，看 MC 是否进入抓取状态。

## 做法

1. 一次性副本 `p237-world`（来自 p229 测试世界）；
2. `AttachThreadInput(当前线程, 前台窗口线程)` → `BringWindowToTop` → `SetForegroundWindow` →
   `SetFocus` → 解除 attach；
3. 点窗口中心最多 3 次，每次用“把光标移到角落、看游戏是否把它吸回中心”判断抓取；
4. 只有抓取成立才按 `E` 验证背包。

## 结果（`result.json`）

| 检查 | 结果 |
|---|---|
| 进入世界 | ✅ |
| 强抢焦点后窗口在前台 | ✅ |
| 鼠标被抓取 | ❌ **false（3 次点击都没有）** |
| 背包打开 | ❌ 未验证（前置条件不成立） |

## 结论

- 在这个合成输入环境里，**没法通过模拟点击让 MC 进入光标抓取状态**；p235 的结论保持不变：
  聊天键（`keyPressed` 直接处理）可用，背包/暂停键（`handleKeybinds` 依赖抓取）**无法用这条路径验证**；
- 没有用“改代码/改配置绕过”的方式假装通过；这条边界继续挂着。

## 边界

- 单客户端、1.20.4 原版、单显示器；
- 判据是光标是否被吸回中心 + 画面差异；
- 脚本在没有抓取时明确记录 `inventory_opens: false` 并在注释里说明“false 是结论，不是通过”。
