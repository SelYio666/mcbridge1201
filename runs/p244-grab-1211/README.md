# p243 — 1.21.1 差分：抓取失败不是 1.20.4 独有

日期：2026-11-03。p235–p239 的结论都来自 1.20.4；本回合在 **1.21.1**（Fabric）上做同一实验，
判断“合成点击抓不住光标”是不是版本特有的。

## 做法

- 用 `work/launcher-e2e/saves/ColdWorldMap`（1.21.1 测试世界）的一次性副本 `p243-world`；
- `fabric-loader-0.19.5-1.21.1` quickplay 进世界；
- 前台校验 → 点击窗口中心 → 移动鼠标 → 截图比“视角是否转动”。

## 结果（`result.json`）

| 检查 | 1.20.4（p238） | 1.21.1（本回合） |
|---|---|---|
| 进世界 / 前台 | ✅ | ✅ |
| 移动鼠标后视角转动（抓取成立） | ❌ 1.68 | ❌ **0.60** |

## 结论

- **不是版本特有的**：1.21.1 同样抓不住，说明这是这台机器上“合成点击 → GLFW 光标抓取”这条路径的
  共性限制，而不是 1.20.4 的怪癖；
- 背包/暂停键（依赖抓取）继续按“未验证”记录；
- 聊天键不受影响（p235 已验证）。

## 边界

- 两个版本各测一次，不是多次重复；
- 判据同 p238（160×90 缩略图平均通道差，阈值 3）；
- 没有改客户端代码/配置来绕过。
