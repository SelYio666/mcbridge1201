# p238 — 更硬的抓取判据：视角不转，说明点击确实没让 MC 抓光标

日期：2026-11-03。p235/p237 用“光标会不会被吸回中心”判断抓取，本回合换成更直接、无法伪造的判据：
**抓取状态下移动鼠标会转动视角**。如果点击真的让 MC 抓了光标，视角必然变化；没变化就是没抓住。

## 做法

1. `p229-world` 的一次性副本 `p238-world`，quickplay 进世界；
2. 前台校验 → 点击窗口中心一次（本意是抓光标）；
3. 截图 → 把鼠标右移 260 px、再右下移 → 截图；
4. 两张图的差异 > 3 才算“视角转动”（抓取成立）；
5. 只有抓取成立才按 `E` 验背包。

## 结果（`result.json`）

| 检查 | 结果 |
|---|---|
| 进入世界 | ✅ |
| 窗口在前台 | ✅ |
| 相机转动（抓取成立） | ❌ **false，差异 1.68** |
| 背包打开 | ❌ 未验证（前置不成立） |

## 结论

- 两种独立判据（p235/p237 的光标回收、p238 的视角转动）都表明：**合成点击没有让 MC 进入光标抓取状态**；
- 因此背包/暂停键（`handleKeybinds` 依赖抓取）通过合成输入**无法验证**，这条边界继续挂着；
- 聊天键不受影响（p235 已验证）。

## 边界

- 单客户端、1.20.4 原版、单显示器；
- 判据是画面差异（160×90 缩略图平均通道差），阈值 3；
- 没有改代码或改配置来“强行通过”。
