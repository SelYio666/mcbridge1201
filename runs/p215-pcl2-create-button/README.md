# p215 — “创建世界页底部按钮不吃合成点击”重跑（结论：旧结论不成立，问题仍未定死）

日期：2026-10-30（首次尝试）/ 2026-10-30 22:26-22:30（本次重跑）。

## 为什么要重跑

第一次 p215 把多个动作串成一次连续输入，验证器自己的判据都没过
（`the_run_actually_clicked_the_bottom_row_twice` = false，只记录到 1 次点击），
所以“底部按钮忽略合成点击”这句话没有证据支撑，报告里也标明“未形成结论”。

## 这次做了什么

- 给 `runs/p213-pcl2-offline-launch/drive_pcl.py` 增加**窗口相对点击**（`click-win` / `move-win`），
  因为 PCL2 窗口位置与 3 天前不同，旧绝对坐标（608,820 等）已失效；
- 用真实 PCL2（`D:\浏览器所下载文件\我的世界PCL2启动器_2.12.8.2\plain craft launcher 2.exe`）
  启动 1.20.4，进入“选择世界”界面；
- 在同一个游戏窗口上，一次动作一张截图：
  - 点击“创建新的世界” `(594,428)`；
  - 点击上半部 `(435,205)`；
  - hover `(277,437)`、hover `(585,437)`；
  - 点击 `(277,437)`、点击 `(585,437)`；
  - Esc。

## 观察到的结果（与旧结论冲突）

1. 点击 `(594,428)` 后截图**仍然是“选择世界”列表**，没有进入创建页；
2. 点击 `(435,205)` 的结果是**选中了“新的世界”这个存档行**（行变高亮），不是切换游戏模式；
3. 点击 `(277,437)` 之后，游戏**真的进入了选中的世界**：
   `latest.log` 出现 `Time elapsed: 2678 ms`、`SelYio加入了游戏`（22:29:09），
   随后客户端停在死亡界面（该世界是极限/已死亡状态），见 `redo/create-before2.png`。

也就是说：**合成鼠标点击在这个窗口上是生效的**（277,437 的“进入选中的世界”被按下了），
旧结论“底部那一行按钮不吃点击”至少不能这样下——当时很可能是在“选择世界”界面，
把 `277,437` 误当成创建页的“创建新的世界”，实际按到的是“进入选中的世界”。

## 还不能下结论的部分

- 为什么点击 `(594,428)` 没有打开创建页，这次没有查清（坐标偏差、窗口 DPI、按钮状态都可能）；
- 因此“创建页底部按钮是否接受合成点击”仍未定死；
- 下次应先用键盘（报告已证明 Tab/Space/Enter 可用）打开创建页，再对每个按钮做
  “hover 截图 → 单击 → 截图”，并在点击前用截图确认按钮矩形，避免再拿错界面。
