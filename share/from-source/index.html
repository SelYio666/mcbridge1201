三步装好 Minecraft（用下载源）

1.20.1 / 1.21.1 通用 · 一条命令完成“清单 → 客户端 → 库 → 资源 + 校验”
难度：简单 磁盘：约 1 GB 耗时：3–10 分钟（看网速） 前提：装了 Python 3
想自己用下载源装，但不想手动抄 URL、拼 classpath？这份教程把 9 步压成 3 步： 脚本会按公开源下载并逐个校验 sha1，失败自动换 BMCLAPI 镜像。
1

装对应版本的 Java

游戏版本Java
1.16.5 及更早8
1.18 – 1.20.4（含 1.20.1）17
1.20.5+（含 1.21.1）21
java -version   # 确认大版本号
2

跑一条命令

python tools/from_source_install.py --version 1.21.1 --root D:\MC

它会依次做：

  1. 取版本清单，找到该版本的 JSON；
  2. 下载客户端 jar（sha1 校验）；
  3. 下载全部 libraries，解压 Windows natives；
  4. 下载资源索引和约 3900 个资源对象；
  5. 失败自动换 BMCLAPI 镜像重试，并打印进度。
换版本只改 --version；换目录只改 --root。断网重跑会跳过已下好的文件。
列出所有可选版本：--list（默认正式版）、--list --version-type all（含快照/远古）； --version latest 装最新正式版，--version latest-snapshot 装最新快照。
3

启动，或一键对接 PCL

方式 A：一键装进 PCL（推荐，不用手动找目录）。

A0：免 Python 安装器（最省事）：下载 release 里的 mcbridge-pcl-setup.zip → 解压 → 双击 mcbridge-pcl-setup.exe， 按提示回车即可。

A1：已有 Python：

python tools/from_source_install.py --version 1.21.1 --pcl
# PCL2 便携版（自带 .minecraft）：指向它的启动器目录
python tools/from_source_install.py --version 1.21.1 --pcl2 "D:\...\PCL2目录"
# 或双击：share\pcl-onclick\一键装到PCL.bat

脚本会自动找 PCL 的游戏目录（%APPDATA%\.minecraft 或 PCL 设置里的目录）， 把版本装进去并写 launcher_profiles.json；打开 PCL 刷新版本列表即可看到 1.21.1。

方式 B：手动导入：打开 PCL →「设置 → 游戏目录」选 D:\MC（或拖进 PCL 窗口）→ 选中版本 → 启动。

用本项目启动器启动（读的就是这个目录）：

python launcher/mclaunch.py verify 1.21.1 "D:\MC"
python launcher/mclaunch.py launch 1.21.1 "D:\MC" 你的名字
PCL 只负责启动、不负责下载；下载已经由第 2 步完成。Java 记得选 17/21。
?

不想跑脚本？

直接用官方启动器或 HMCL 下载同版本即可（它们内置了这些源）。脚本的意义是：不依赖启动器、可控源、可校验、可脚本化。

合规提示：请通过官方渠道购买/登录 Minecraft；本教程只使用公开下载地址，不提供、不托管、 不分发游戏文件。请遵守 Minecraft EULA。
附：手动 9 步速查（给想自己实现的人）
步骤要点
1 清单piston-meta.mojang.com/mc/game/version_manifest_v2.json，找目标版本 url
2 版本 JSON含 client / libraries / assetIndex / mainClass
3 客户端 jardownloads.client.url + sha1
4 库按 artifact.path/url/sha1 放进 libraries/；natives 解压到 versions/<id>/natives
5 资源索引 + objects/<h2>/<hash>，来自 resources.download.minecraft.net
6 Java1.18–1.20.4→17，1.20.5+→21
7 启动主类 net.minecraft.client.main.Main，参数含 assetsIndex/assetDir/gameDir，手写易错
8 镜像BMCLAPI 的 assets/maven 与官方路径一一对应
9 验收库齐、资源齐、能进主菜单；错误看 latest.log
