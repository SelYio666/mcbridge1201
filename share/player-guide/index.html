二、先拿到游戏文件，再导入启动器

PCL 目前不提供 Minecraft 版本下载，所以流程是：先用官方启动器（或其它能下载的启动器）下载 1.21.1，再把它导入 PCL 启动。HMCL / Prism 一般仍可自行下载，也可以用同样的“导入”方式。

第 1 步：下载 1.21.1（二选一）

  • 官方启动器：安装 → 选 1.21.1 → 播放一次让它下载完整（正版登录）；
  • 其它能下载的启动器（HMCL、Prism 等）：新建 1.21.1 实例即可。

下载完成后，游戏目录一般在 %APPDATA%\.minecraft（Prism 在 %APPDATA%\PrismLauncher\instances\<实例>）。

第 2 步：装 Fabric（如果需要模组/Fabric 版本）

  1. 下载 Fabric Installer（maven 上的 fabric-installer-*.jar）；
  2. 用 Java 21 运行：
java -jar fabric-installer-1.0.1.jar client -dir "C:\Users\你\AppData\Roaming\.minecraft" -mcversion 1.21.1 -noprofile

装好后 versions/ 里会多出 fabric-loader-<版本>-1.21.1。不做模组可以跳过这一步，直接用原版 1.21.1。

第 3 步：导入 PCL 并启动

  1. 打开 PCL →「设置」→「游戏目录」，选择你刚下载的 .minecraft 目录；
  2. 也可以把整个 .minecraft 文件夹（或其中的版本文件夹）拖进 PCL 窗口；
  3. 回到主界面，版本列表里应出现 1.21.1 或 Fabric 版本，选中 →「启动」；
  4. 「设置 → Java」确认选的是 Java 21；
  5. 账户：正版登录，或在 PCL 里用离线模式。
如果 PCL 没扫描到：把 versions/ 下对应的版本文件夹复制到 PCL 当前使用的 .minecraft/versions/ 里，再刷新列表。

HMCL

  1. HMCL 能直接下载：新建 1.21.1 + Fabric 实例即可；
  2. 要复用已有版本：把「游戏目录」指向同一个 .minecraft，版本列表会自动出现；
  3. 「设置 → Java 路径」选 Java 21。

Prism Launcher

  1. 可以自行下载：Add Instance → 1.21.1 + Fabric；
  2. 要复用已有实例：把实例目录放进 Prism 的 instances/，或在 Add Instance 里导入；
  3. 「Edit → Settings → Java」选 Java 21。

官方启动器

  1. 直接选 1.21.1 / Fabric 配置启动即可；
  2. Java 21 可由启动器自动下载。

三、下载慢或失败怎么办

  • 先换镜像（上面的 BMCLAPI），或换个时间段；
  • Mojang 的 CDN 与加载器 Maven 是不同线路，一个慢不代表另一个慢；
  • 下载后建议校验：官方文件都带 sha1（PowerShell 用 Get-FileHash -Algorithm SHA1）；
  • 资源对象没有文件名，按 objects/<hash前2位>/<hash> 存放，路径本身就是校验值。

四、常见问题

现象处理
启动即崩、提示 Java 版本换成 Java 21（1.20.1 用 Java 17）
材质/字体缺失资源没下全，重新安装或换源
多人进不去确认服务端与客户端版本、加载器版本一致
启动器互相覆盖不同启动器用不同游戏目录，或先备份
