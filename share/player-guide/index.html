二、启动器教程

PCL（Plain Craft Launcher 2）

  1. 打开 PCL →「下载」→ 选 1.21.1，同时勾选 Fabric（或 Forge）→ 开始安装；
  2. 装好后回到主界面，选中该版本 →「启动」；
  3. 「设置 → 启动设置」里确认 Java：1.21.1 用 Java 21；
  4. 第一次启动会创建存档目录；进游戏即完成。

HMCL

  1. 「版本列表」→「安装新游戏版本」→ 选 1.21.1，勾选 Fabric；
  2. 安装完成后双击该版本启动；
  3. 「设置 → Java 路径」选 Java 21；
  4. 如果下载慢，可在「设置 → 下载」里切换下载源。

Prism Launcher

  1. 「Add Instance」→ 版本选 1.21.1，Loader 选 Fabric → OK；
  2. 双击实例启动；
  3. 「Edit → Settings → Java」确认是 Java 21；
  4. 需要多个实例时，每个实例有独立目录，互不影响。

官方启动器

  1. 安装 1.21.1，然后运行 Fabric Installer 选择 1.21.1 安装；
  2. 启动器里会多出一个 Fabric 配置，选它启动；
  3. Java 21 可由启动器自动下载（官方运行时）。

三、下载慢或失败怎么办

  • 先换镜像（上面的 BMCLAPI），或换个时间段；
  • Mojang 的 CDN 与加载器 Maven 是不同线路，一个慢不代表另一个慢；
  • 下载后建议校验：官方文件都带 sha1（PowerShell 用 Get-FileHash -Algorithm SHA1）；
  • 资源对象没有文件名，按 objects/<hash前2位>/<hash> 存放，路径本身就是校验值。

四、常见问题

现象处理
启动即崩、提示 Java 版本换成 Java 21（1.20.1 用 Java 17）
材质/字体缺失资源没下全，重新安装或换源
多人进不去确认服务端与客户端版本、加载器版本一致
启动器互相覆盖不同启动器用不同游戏目录，或先备份
