选择你的启动器

PCL2 · 自动检测
python tools/from_source_install.py --version 1.21.1 --pcl
读 PCL2 的 PCL/Setup.ini；找不到就用 --pcl-dir <那个 .minecraft>。
HMCL · 普通安装
python tools/from_source_install.py --version 1.21.1 --hmcl
读 %APPDATA%\.hmcl\config\user-game-directories.json。
HMCL · 便携版 / 自定义目录
python tools/from_source_install.py --version 1.21.1 --hmcl-dir "D:\HMCL\.minecraft"
便携版配置里是相对启动目录的 .minecraft，自动检测拿不到，用这个直接指过去；装完重启 HMCL。

常见问题

Q1 HMCL 里显示“没有游戏实例”？
装到了它不认的目录。看 HMCL 设置里的“游戏目录”；便携版用 --hmcl-dir 指到它的 .minecraft，然后重启 HMCL。
Q2 下载报 SSL: UNEXPECTED_EOF_WHILE_READING？
v0.5.9 已内置连接池和 3 次重试；仍失败多半是网络整体抖动，隔一会儿重跑，已下载的部分会跳过。
Q3 会不会装到我没想到的地方？
v0.5.8 起不会：配置目录必须已存在才用；否则回退便携 .minecraft；都没有就报错停下。
Q4 要手动改 launcher_profiles.json 吗？
不用。安装器会写；PCL/HMCL 主要看 versions/，profile 只是顺手兼容官方启动器。
