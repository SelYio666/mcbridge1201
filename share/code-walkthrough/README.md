上一版是“代码走读”，信息密度太高、不好懂。这一版按“讲给人听”重做：

- **每屏最多 4–5 行**，字号 23–30 px，不做逐行代码朗读；
- 只保留**一个 3 行的配置片段**当例子，其余用比喻和流程讲；
- 节奏放慢（12 字/秒左右）。

## 边界

- 统计数字取自当前仓库快照，会随开发变化；
- 不涉及另一个 agent 正在做的“其他版本适配”内容；
- 只讲主干（转换/启动器/安装/证据），不逐文件讲全部代码。
