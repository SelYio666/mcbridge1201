从零开始：Minecraft 安装到启动

1.20.1 / 1.21.1 / 最新版本都适用 · 不需要 GitHub · 不需要写代码
系统：Windows 10/11 64 位 磁盘：约 3–5 GB 耗时：15–30 分钟 关键：版本、Java、启动器要对上
流程：①选版本 → ②看配置 → ③装对 Java → ④下载游戏 → ⑤装加载器（可选）→ ⑥导入 PCL → ⑦启动验收
1

先选一个游戏版本

不要一上来就装最新版——先看你想玩什么。版本、Java、加载器三者必须配套。

版本适合谁Java常用加载器
1.20.1模组生态最全，整合包/Forge 模组首选17Forge、Fabric
1.21.1较新、Fabric 模组主流，性能模组多21Fabric、NeoForge
最新 1.21.x想玩最新内容；模组可能还没跟上21Fabric、NeoForge
1.16.5 / 1.18.2老整合包；Java 要求不同8 / 17Forge、Fabric
跟着服务器玩：服务器是什么版本，客户端就装什么版本，加载器也要一致。
2

确认电脑够用

  • 系统：Windows 10 / 11，64 位；
  • 内存：建议 8 GB 以上（游戏分配 2–4 GB）；
  • 空间：至少 3–5 GB（1.21.1 全量约 900 MB + Java + 余量）；
  • 显卡：能正常看视频即可；集显也能玩。
3

装对应版本的 Java 关键

用官方启动器时它会自动准备合适的 Java；用 PCL/HMCL 或手动装加载器，需要自己装对版本：

游戏版本必需 Java
1.16.5 及更早Java 8
1.17Java 16（用 17 也行）
1.18 – 1.20.4Java 17
1.20.5 及以上（含 1.21.x）Java 21

推荐 Eclipse Temurin（JDK/JRE 都行），装完验证：

java -version
# 例如：openjdk version "17.0.12" / "21.0.7"
版本不对常见报错：UnsupportedClassVersionError、启动即崩。
4

下载游戏文件

注意：PCL 目前不提供版本下载，这一步要用能下载版本的启动器。

  1. 官方启动器（推荐）：登录微软账号 → 选你要的版本（如 1.21.1 或 1.20.1）→ 点“播放”一次，等它下载完进入主菜单；
  2. 或者用 HMCL：新建同版本实例，让它下载（支持离线登录）；
  3. 下载完成后，游戏目录一般在 %APPDATA%\.minecraft。
下载慢/失败：换时间段，或用 BMCLAPI 镜像；镜像与官方各线路不同，加载器 Maven 也不等于 Mojang CDN。 详细地址见“下载源速查”。
5

安装加载器 可选

只玩原版可以跳过。要玩模组：Fabric（新版本主流）、Forge（1.20.1 生态最大）、NeoForge（1.20.2+ 主流）。

Fabric：下载 fabric-installer-*.jar，用对应版本的 Java运行：

java -jar fabric-installer-1.0.1.jar client -dir "C:\Users\你\AppData\Roaming\.minecraft" -mcversion 1.21.1 -noprofile
# 1.20.1 把 1.21.1 换成 1.20.1；Java 也要换成 17

Forge / NeoForge：下载对应版本的 installer（Forge 用 forge-<MC>-<forge>-installer.jar）， 双击或用 Java 运行，选 “Install client”。

成功后 versions/ 里会多出 fabric-loader-...-<版本> 或 forge-<版本>。

6

导入 PCL 并启动

  1. 打开 PCL →「设置 → 游戏目录」，选第 4 步的 .minecraft；或把整个文件夹拖进 PCL 窗口；
  2. 主界面版本列表里选中你装的版本（原版或加载器版本）→ 点「启动」；
  3. 「设置 → Java」选对应版本的 Java（1.20.1→17，1.21.1→21）；
  4. 账号：正版登录，或在 PCL 里选离线模式；
  5. 第一次启动会创建存档目录，进入主菜单即成功。
PCL 没扫到版本？把 versions/ 下对应版本文件夹复制到 PCL 使用的 .minecraft/versions/ 里，再刷新列表。
7

验收与排查

  • 能看到主菜单和“单人游戏/多人游戏”；
  • 新建世界能进、能走能破坏方块；
  • 有问题看 .minecraft/logs/latest.log，搜 ERROR / Exception。
现象处理
启动即崩、提示 Java 版本按第 3 步换对 Java（1.20.1→17，1.21.1→21）
黑屏/闪退更新显卡驱动；内存别开太小；看 latest.log
模组加载失败确认加载器类型与版本（Fabric 模组不能放 Forge）
材质/字体缺失资源没下全，重装或换下载源
启动器互相覆盖不同启动器用不同游戏目录，先备份
合规提示：请通过官方渠道购买/登录 Minecraft；本教程不提供、不托管、不分发游戏文件。 离线模式仅适合自己测试，请遵守 Minecraft EULA 与各启动器的服务条款。
