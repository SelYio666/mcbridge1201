从零开始：Minecraft 1.21.1 安装到启动

不需要 GitHub · 不需要写代码 · 适合第一次装 Minecraft 的人
系统：Windows 10/11 64 位 磁盘：约 3 GB 耗时：15–30 分钟（看网速） 版本：1.21.1
流程：①看配置 → ②装 Java → ③下载游戏 → ④装 Fabric（可选）→ ⑤导入 PCL → ⑥启动
1

确认电脑够用

  • 系统：Windows 10 / 11，64 位；
  • 内存：建议 8 GB 以上（游戏分配 2–4 GB）；
  • 空间：至少留 3 GB（1.21.1 全量约 900 MB + Java + 余量）；
  • 显卡：能正常看视频即可；集成显卡也能玩，但帧数低。
2

准备 Java 21 可选

用官方启动器时它自带 Java，可跳过这步；用 PCL/HMCL 或手动装 Fabric，建议先装 Java 21。

  1. 下载 Eclipse Temurin 21（JDK/JRE 均可）安装；
  2. 装完打开命令提示符，验证：
java -version
# 看到 21.x 即可，例如：openjdk version "21.0.7"
1.20.1 用 Java 17；1.21.1 用 Java 21。版本不对会报 UnsupportedClassVersionError。
3

下载 1.21.1 游戏文件 关键

这一步必须有一个能下载版本的启动器。注意：PCL 目前不提供版本下载。

  1. 官方启动器（推荐，最省心）：安装 → 登录微软账号 → 选 1.21.1 → 点“播放”一次，等它下载完进入主菜单；
  2. 或者用 HMCL：新建 1.21.1 实例，让它下载（HMCL 支持离线登录）；
  3. 下载完成后，游戏目录一般在 %APPDATA%\.minecraft。
下载慢/失败：换时间段，或用 BMCLAPI 镜像（资源 bmclapi2.bangbang93.com/assets/<hash前2位>/<hash>）， 镜像的详细地址见“下载源速查”。
4

安装 Fabric 可选

只玩原版可以跳过；要玩 Fabric 模组才需要。

  1. 下载 fabric-installer-*.jar（Fabric 官网/maven）；
  2. 用 Java 21 运行，安装到你的游戏目录：
java -jar fabric-installer-1.0.1.jar client -dir "C:\Users\你\AppData\Roaming\.minecraft" -mcversion 1.21.1 -noprofile

成功后 versions/ 里会多出 fabric-loader-<版本>-1.21.1。

5

导入 PCL 并启动

  1. 打开 PCL →「设置 → 游戏目录」，选第 3 步的 .minecraft；或把整个文件夹拖进 PCL 窗口；
  2. 主界面版本列表里选中 1.21.1（或 Fabric 版本）→ 点「启动」；
  3. 「设置 → Java」选 Java 21；
  4. 账号：正版登录，或在 PCL 里选离线模式；
  5. 第一次启动会创建存档目录，进入主菜单即成功。
PCL 没扫到版本？把 versions/ 下对应版本文件夹复制到 PCL 使用的 .minecraft/versions/ 里，再刷新列表。
6

检查是否成功 验收

  • 能看到 Mojang 主菜单和“单人游戏/多人游戏”；
  • 开一个新世界能进得去、能走动能破坏方块；
  • 有问题看日志：.minecraft/logs/latest.log，搜 ERROR / Exception。
现象处理
启动即崩、提示 Java 版本换成 Java 21（1.20.1 用 17）
黑屏/闪退更新显卡驱动；内存别开太小；看 latest.log
材质/字体缺失资源没下全，重装或换下载源
启动器互相覆盖不同启动器用不同游戏目录，先备份
合规提示：请通过官方渠道购买/登录 Minecraft；本教程不提供、不托管、不分发游戏文件。 离线模式仅适合自己测试，请遵守 Minecraft EULA 与各启动器的服务条款。
