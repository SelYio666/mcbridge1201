这页是什么：把启动器/整合包/服主常用的官方下载入口整理成一张表。它不是给普通玩家 手抄下载用的——普通玩家直接用官方启动器或 HMCL 下载即可（它们内置了这些源）。

谁需要它：① 启动器下载慢/失败、想切镜像的人；② 手动安装 Fabric/Forge 的人； ③ 自建服务器或写下载脚本的人；④ 想核对文件 sha1 的人。 本页不托管、不分发游戏或模组文件，只列公开链接。

一、Mojang 官方源

用途地址说明
版本清单 piston-meta.mojang.com/mc/game/version_manifest_v2.json 所有版本（含快照/远古）的入口；每个版本带自己的 JSON 地址
版本 JSON / 客户端 jar 从清单里该版本的 url 取；jar 在 JSON 的 downloads.client.url 客户端 jar 约 26 MB，带 sha1
库（libraries） libraries.minecraft.net 具体路径以版本 JSON 的 libraries[].downloads.artifact.url 为准
资源（assets） resources.download.minecraft.net/<hash前2位>/<hash> 索引在 JSON 的 assetIndex.url；文件按 sha1 命名
Java 运行时清单 launchermeta.mojang.com/.../java-runtime/all.json 官方 JRE 组件（jre-legacy / gamma / delta / epsilon 等）

五、怎么验证下载没被改

所有官方文件都带 sha1：版本 JSON、库、资源索引里都有。下载后校验：

# Windows PowerShell
Get-FileHash .\1.21.1.jar -Algorithm SHA1

# Linux / macOS
sha1sum 1.21.1.jar

资源对象没有文件名，直接按 objects/<hash前2位>/<hash> 存放，路径本身就是校验值。

六、常见问题

官方 CDN 一直超时？先用镜像下资源；库和加载器优先官方 Maven，失败再切镜像。

Forge/NeoForge 安装器下不动？它们各自在自己的 Maven（forge 用 maven.minecraftforge.net， neoforge 用 maven.neoforged.net），和 Mojang CDN 不是一个线路。

版本号怎么写？Forge 是 <MC>-<forge>（如 1.20.1-47.4.16）； NeoForge 是纯数字（如 21.1.264，对应 MC 1.21.1）。
