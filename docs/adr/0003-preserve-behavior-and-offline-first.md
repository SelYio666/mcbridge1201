# 第一版使用启动前转换，并保留行为失败的可见性

第一版先在独立实例中完成离线转换，再由正常加载器发现转换产物和目标兼容桥，避免依赖尚未证明可行的运行时发现顺序与类加载钩子。后续“放入旧 jar 自动运行”的体验，由实例预启动步骤提供；只有证明加载器的官方扩展点能在发现和求解之前执行，才接入加载器内部自动转换。

缺失 API 的空实现、删除 Mixin 和延迟抛错会让启动成功掩盖玩法缺失，生产路径默认拒绝未解决的必要行为。已知可选功能可通过明确档案降级并记录，研究模式可以输出带失败桩的产物，但不得据此宣称完整兼容。
